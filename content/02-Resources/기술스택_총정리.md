# 기술 스택 총정리

> 대형언어모델활용건축공학인공지능구현 (15주) 강의에 필요한 기술 스택 정리

## 1. LLM 플랫폼 & API

| 기술 | 용도 | 도입 주차 | 비용 |
|-----|------|:-------:|------|
| **Anthropic Claude API** (`anthropic`) | 메인 API, Streaming, Tool Use, MCP, Prompt Caching | 1, 3-7, 9-13 | 유료 (API) |
| **OpenAI GPT-4o API** (`openai`) | API 비교, 대안, 임베딩 | 1, 4-5 | 유료 (API) |
| **Google Gemini API** (`google-generativeai`) | 긴 컨텍스트(1M), 멀티모달, PDF 처리 | 1, 4, 6 | 유료 (무료 티어 있음) |
| **Google AI Studio** | 프롬프트 실험 (웹 UI) | 1 | 무료 |
| **Google NotebookLM** | No-code RAG 체험 | 5 | 무료 |
