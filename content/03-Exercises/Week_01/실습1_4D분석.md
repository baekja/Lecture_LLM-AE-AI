# 실습 1: 4D 분석 — 모범 답안

> [!ref] 실습 지시사항: [[Week_01#실습 1: 4D 분석 (20분) → Ch.1]]

## 수행 결과

| 4D | 질문 | 모범 답안 |
|---|---|---|
| **Delegation** (위임) | 이 작업에서 AI에 위임할 부분은? 인간만이 해야 할 판단은? | |
| **Description** (기술) | AI에게 어떤 맥락과 조건을 제공해야 하는가? | |
| **Discernment** (판별) | AI 결과를 어떤 기준으로 검증할 것인가? | |
| **Diligence** (성실) | AI 활용 사실을 어떻게 투명하게 밝힐 것인가? | |

## 채점 포인트

- [ ] 각 D에 대해 2문장 이상 구체적 작성 여부
- [ ] 건축공학 도메인에 맞는 적절한 예시 포함 여부
- [ ] AI 위임 범위와 인간 판단 영역의 명확한 구분 여부
